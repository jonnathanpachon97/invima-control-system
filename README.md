# INVIMA Control System

Sistema web para digitalización de formatos INVIMA.

## Características

- Gestión de formatos dinámicos
- Captura de registros
- Evidencias fotográficas
- Aprobación y rechazo de registros
- Generación de PDF
- Exportación a Excel
- Dashboard estadístico
- Responsive para móviles

## Tecnologías

### Backend
- Django
- Django REST Framework
- PostgreSQL

### Frontend
- React
- Tailwind CSS
- Axios
